# V1 — revised few-shot portfolio

Open `index.html` directly or serve this folder with a static HTTP server. This V1 was rebuilt from the frozen V0 for the 31 October few-shot run. The exact fictional before/after input is in `evaluation/experiments/V1_fewshot/V1_rebuild_input_2026-10-31.md` in the submission pack. Both project cards use a two-column goal/contribution layout on wide screens, with three first-person action bullets each; the panels stack on narrow screens. `nav.js` marks the active section and adjusts the anchor offset for the sticky header.

The real project text comes from V0; fictional example facts were not copied. Text is editable in `content.js` and inserted by `render.js`. Images were supplied by the owner. DM Sans and DM Serif Display load from Google Fonts with system fallbacks. The education links point to the official SCNU Aberdeen Institute and PolyU programme pages.

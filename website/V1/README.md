# V1 — example-guided portfolio

Open `index.html` directly or serve this folder as static files. V1 was copied from the user's 30 October V0 snapshot. Three fictional before/after examples guide the case-study layout, first-person action lists, and navigation behavior. All project facts are already present in V0. Site text is editable through `content.js` and applied by `render.js`; `nav.js` marks the current section. Images were supplied by the owner. DM Sans and DM Serif Display load from Google Fonts with system fallbacks.

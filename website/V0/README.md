# V0 Personal Website

Static single-page site. Open `index.html` inside a packaged `website/V0` folder. The page can also be served with any static HTTP server. No build step or backend is required.

The page contains Home, About, Projects, and Contact sections. Project 01 is a 2023 social practice project; Project 02 is a 2025 internship.

Source files: `index.html`, `styles.css`, `content.js`, `render.js`, and the images in `assets/`.

Credits: The Steam screenshot and both university logo images were supplied by the site owner. Fonts are DM Sans and DM Serif Display via Google Fonts, with system fallbacks. The education links point to the official [SCNU Aberdeen Institute](https://abdn.scnu.edu.cn/english/about/) and [PolyU MSc](https://www.polyu.edu.hk/comp/study/taught-postgraduate-programme/mscas/) pages.
